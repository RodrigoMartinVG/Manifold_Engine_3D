El tutorial acompaña la construcción de Manifold Gaming, pero **simplificado**: cada lección toma **una** idea de una etapa del motor y la muestra con un código chico que corre **aquí mismo**. No hace falta instalar nada.

- **Cambiá el código y ejecutalo** (▶, o Ctrl/⌘ + Enter). Lo que escriba con `console.log` aparece debajo.
- **Varios archivos**: cuando una lección tiene pestañas, es para mostrar cómo se reparte el código en módulos.
- **↺ Restaurar** vuelve al código original.
- **⛶ Pantalla completa** pone el código y lo que dibuja lado a lado, ocupando toda la pantalla (en un celular, uno arriba del otro). La línea del medio se arrastra para darle más lugar a uno o al otro. Esc vuelve.
- Es **TypeScript de verdad**: el navegador ejecuta el mismo código que está en el [repositorio](https://github.com/RodrigoMartinVG/Manifold_Gaming/tree/main/sitio/src/lecciones), revisado por el compilador y probado en cada cambio.

El detalle de lo que hicimos en cada etapa (los hallazgos, las mediciones, las decisiones) está en la **Bitácora**.

Probá: cambiá el `1` por `10` y ejecutá.
