## La consola del Dojo

La consola está en inglés y no se traduce: sus nombres son como las palabras de un lenguaje de programación. Todo esto se puede escribir en ella, y `help` lo explica desde adentro.

| En español       | En inglés        | Qué es                                                                                        |
| ---------------- | ---------------- | --------------------------------------------------------------------------------------------- |
| consola          | _console_        | se abre con la tecla **º** (o `` ` ``)                                                        |
| comando          | _command_        | una orden: `restart`, `load rain`                                                             |
| variable         | _variable_       | un valor con nombre: `dojo.cubes 20`                                                          |
| receta           | _recipe_         | un texto con valores, uno por línea; viaja en un enlace con `#recipe=`                        |
| sala             | _room_           | una receta guardada, con su dirección: `load rain`                                            |
| receta de inicio | _startup recipe_ | la que corre siempre al entrar, en tu navegador: `startup save`                               |
| atajo            | _key binding_    | una tecla para un comando: `bind t toggle show.axes`                                          |
| valor de siempre | _default_        | el que tiene una variable si nadie la cambió                                                  |
| alcance          | _scope_          | cuándo entra un cambio: al empezar (_startup_), en el paso siguiente (_world_), o ya (_view_) |

Y los nombres que hay hoy:

| Nombre            | Qué hace                                                                                                                          |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `help`            | cómo se usa la consola, o la ayuda de un nombre: `help seed`                                                                      |
| `find`            | busca en los nombres y en sus descripciones: `find cube`                                                                          |
| `vars`            | las variables y sus valores; `vars show.` muestra solo las que empiezan así                                                       |
| `changed`         | solo las variables que no tienen su valor de siempre                                                                              |
| `toggle`          | da vuelta una variable de prendido y apagado (_on_ / _off_): `toggle show.axes`                                                   |
| `export`          | arma un enlace con la receta de lo que cambiaste (_export_: exportar)                                                             |
| `load`            | carga una sala guardada (_load_: cargar); sin nombre, la lista                                                                    |
| `startup`         | la receta de inicio: `startup save` la guarda (_save_), `startup clear` la borra (_clear_)                                        |
| `bind`, `unbind`  | asigna o quita un atajo de teclado (_bind_: atar)                                                                                 |
| `clear`           | borra lo que está escrito en la consola                                                                                           |
| `reset`           | vuelve una variable (o todas, sin nombre) a su valor de siempre: `reset dojo.cubes`                                               |
| `inspect`         | de qué está hecha una entidad, con sus números: `inspect 1` (_inspect_: inspeccionar); un clic sobre un objeto hace lo mismo      |
| `camera.reset`    | la cámara vuelve a donde empezó, o detrás del personaje                                                                           |
| `view.camera`     | con un personaje: `follow` lo sigue, `chase` vuelve detrás de él, `aim` apunta con el mouse, `free` deja la cámara donde está     |
| `controls.scheme` | cómo manejan las teclas al personaje: `camera`, según la cámara, o `tank`, según hacia dónde mira él (_scheme_: esquema)          |
| `replay`          | la repetición de este mundo: `replay export` arma un enlace, `replay play` la vuelve a mostrar, `replay stop` devuelve el control |
| `snapshot`        | guarda este momento del mundo; `snapshot load` vuelve a él                                                                        |
| `net`             | la partida y dónde vive: `net open` la abre a otras pestañas, `net join` se une a una, `net leave` vuelve a jugar solo            |
| `inputs`          | lo que un jugador puede pedir en este juego, y qué tecla lo pide                                                                  |
| `ghost`           | vuelve a empezar con un fantasma que repite lo que hiciste; `ghost export` arma el enlace, `ghost clear` lo saca                  |
| `seed`            | la semilla del azar del mundo                                                                                                     |
| `physics.gravity` | la gravedad, en m/s² en cada eje: la de la Tierra es `0 -9.81 0`                                                                  |
| `restart`         | el mundo vuelve a empezar, con los valores actuales                                                                               |
| `pause`, `step`   | detiene o sigue el mundo; `step 10` avanza diez pasos y lo deja en pausa                                                          |
| `hash`            | el paso del mundo y su huella                                                                                                     |
| `show.wireframe`  | las mallas en alambre (_show_: mostrar)                                                                                           |
| `show.axes`       | los ejes del mundo en el origen                                                                                                   |
| `show.physics`    | lo que ve el motor de física: los colisionadores de cada cuerpo, como líneas                                                      |
| `show.vectors`    | la velocidad de cada cuerpo que se mueve, y hacia dónde mira cada personaje                                                       |
| `show.contacts`   | dónde se tocan los cuerpos, con la normal de cada contacto                                                                        |
| `show.gravity`    | el campo de gravedad, como flechas                                                                                                |
| `show.sensors`    | las zonas del nivel, como cajas de alambre: puntos de control en verde, la meta en dorado, el vacío en rojo                       |
| `show.stats`      | el paso, la huella, las entidades y los cuadros por segundo (_stats_: estadísticas)                                               |
| `view.timescale`  | la velocidad a la que se muestra el mundo (no cambia la simulación)                                                               |
| `view.paused`     | el mundo detenido, como variable                                                                                                  |
| `dojo.cubes`      | cuántos cubos chicos caen al empezar (_cubes_: cubos)                                                                             |
| `dojo.spin`       | cómo gira el cubo grande, en radianes por segundo alrededor de cada eje                                                           |
| `dojo.spawn`      | tira una pelota desde un lugar: `dojo.spawn 2 5 0` (_spawn_: hacer aparecer)                                                      |
| `dojo.level`      | lo que hay en el piso: `empty`, o un nivel de `games/dojo/levels/`, como `course`, con un personaje para manejar                  |
